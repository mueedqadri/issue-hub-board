## Description

**What the user will notice:** After landing in another time zone, widgets show local times right away.

### Cause

The timeline kept entries computed in the old zone.

### Fix

Rebuild the timeline on significant time change.

- Seen working on a device, as described above.
- A test that fails before the change and passes after.
