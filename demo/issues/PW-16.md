## Description

**What the user will notice:** Scrolling back to an area you just looked at shows it instantly.

### Cause

Every pan re-downloads tiles.

### Fix

An on-disk tile cache keyed by time step, evicted after an hour.

### Acceptance

- Seen working on a device, as described above.
- A test that fails before the change and passes after.
