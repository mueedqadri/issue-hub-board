## Description

**What the user will notice:** "Feels like" in a humid heat wave is higher than the air temperature, as it should be.

### Cause

Only wind chill is applied.

### Fix

Use the heat index above 27 °C.

### Acceptance

- Seen working on a device, as described above.
- A test that fails before the change and passes after.
