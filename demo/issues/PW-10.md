## Description

**What the user will notice:** Panning the radar map stays smooth at 120 Hz instead of stuttering.

### Cause

Tiles are decoded and composited on the main thread; a pan drops to about 40 fps on an iPhone 13.

### Fix

Decode tiles off the main thread and composite them in a Metal layer.

### Acceptance

- Seen working on a device, as described above.
- A test that fails before the change and passes after.
