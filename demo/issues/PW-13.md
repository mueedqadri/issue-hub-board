## Description

**What the user will notice:** Light and heavy rain are clearly different for people with red-green color blindness.

### Cause

The scale runs green to red, which deuteranopia flattens.

### Fix

Switch to a blue-to-purple scale with lightness steps, and label the legend with words.

- Seen working on a device, as described above.
- A test that fails before the change and passes after.
