## Description

**What the user will notice:** The radar no longer closes the app when a tile is missing.

### Cause

A zero-byte PNG reached the decoder, which force-unwrapped the result.

### Fix

Treat an undecodable tile as missing and retry it once.

### Acceptance

- Seen working on a device, as described above.
- A test that fails before the change and passes after.
